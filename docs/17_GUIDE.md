# 17 — Compost Guide

## 1. Obiettivo

La guida è parte del prodotto, non documentazione secondaria.

Deve rendere l'app comprensibile a:

- principiante;
- utente domestico;
- utente avanzato.

## 3. Contextual help

Una diagnostica deve puntare alla sezione corretta.

Esempi:

> Why is it too wet?

→ Moisture.

> Why does temperature matter?

→ Temperature.

> Why is "ready" only estimated?

→ Maturity.

## 4. Scientific caution

La guida non deve trasformare una regola pratica in una legge universale.

Usare:

- generally;
- often;
- may;
- depends on.

## 5. Language

La UI può essere semplice.

Gli approfondimenti possono essere più tecnici.
