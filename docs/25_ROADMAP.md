# 25 — Roadmap

## Principio

Il progetto deve crescere per capacità.

Non tentare di realizzare ogni feature contemporaneamente.

## Phase 0 — Foundation

Obiettivo:

- repository;
- docs;
- skeleton;
- Config Flow;
- tests.

Successo:

> Home Assistant carica l'integrazione e l'utente può configurarla.

## Phase 1 — Zero Sensor MVP

Implementare:

- bin;
- cycle;
- materials;
- observations;
- interventions;
- provenance;
- basic assessment;
- guide;
- derived entities.

Successo:

> Il prodotto è utile anche senza sensori.

## Phase 2 — Temperature Intelligence

Implementare:

- internal temperature binding;
- thermal time series;
- trends;
- peaks;
- cooling;
- phase inference;
- thermal health.

## Phase 3 — Moisture + Aeration

Implementare:

- internal humidity;
- moisture diagnostics;
- compaction;
- structure;
- aeration inference;
- rain interaction.

## Phase 4 — Material Intelligence

Implementare:

- material catalogue;
- green/brown;
- structure;
- moisture contribution;
- quantity precision;
- contextual balance.

## Phase 5 — Weather + Forecast

Implementare:

- weather context;
- rain forecast;
- temperature forecast;
- drying risk;
- cold/heat context.

## Phase 6 — Events + Notifications

Implementare:

- event detection;
- notification engine;
- persistence;
- cooldown;
- recovery;
- priority.

## Phase 7 — Multi-bin + Batch Intelligence

Consolidare:

- isolation;
- batch comparison;
- personal baselines;
- cycle reports.

## Phase 8 — Maturity

Implementare:

- maturity assessment;
- readiness semantics;
- continuous vs batch;
- maturity forecast.

## Phase 9 — Advanced Signals

Aggiungere solo se realmente utili:

- VOC;
- NH3;
- CO2;
- weight;
- fill;
- pH;
- EC/salinity.

Ogni segnale deve avere un ruolo diagnostico definito.

## Phase 10 — Learning

Implementare:

- intervention response;
- personal statistics;
- seasonal trends;
- improved forecast.

## Phase 11 — Release readiness

- translations;
- diagnostics;
- repairs where needed;
- documentation;
- CI;
- HACS;
- GitHub.

## Future

Possibili:

- ML;
- garden management;
- compost inventory;
- agronomic advice;
- advanced sensor fusion.

## Roadmap rule

Se una feature avanzata compromette:

- reliability;
- provenance;
- explainability;
- performance;

va rimandata.
